# REMAKE — source-qualified cinematic craft context v1

**Draft, not released.** The private role100 Cinematic Craft Atlas is not included in this public plugin. The public REMAKE MCP currently has no authenticated read access to private GitHub. `remake_get_audit_method({"section":"craft"})` returns the public method only, not the private corpus and not a creative verdict.

When a host has separately obtained an authorized local `objekts.craft-context/1` packet, inspect its `source_digest_sha256`, task/LOCK/asset authorities, candidate KN-IDs, provenance, source scope, counterexamples and proposed tests. Select only scene-relevant mechanisms. Connect authorial purpose, actor blocking, camera position, perspective/focus, motivated light/material, acoustic POV, edit and VFX finishing where causal. The actual scene, script, supplied image/video and latest user approvals remain authoritative. Do not mark an extracted interview as a watched film or a tested shot.

**Use log:** maintain private `considered_ids`, `used_ids`, `rejected_ids`, affected scene locator, original source, LOCK check, untested risk and real output QA. Retrieval does not prove artistic application; a source-inspired decision does not prove successful rendering. Never demand use of all relevant mechanisms as aesthetic decoration.

**Privacy:** do not send the private Atlas, confidential client assets or source snippets to the unauthenticated REMAKE MCP just to get instructions. This is an OPTIONAL host-side method. No automatic retrieval, project storage, model generation, outbound transfer or production validation is performed by this file. Source status remains research proposal until approved by owner.

## Integrated source decision receipts (draft)

With a private packet *actually supplied by an authorized host*, the host may record its final diagnosis using the local OPS module `tools/craft_consumer_verified.mjs`. Schema: `objekts.craft-consumer-receipt/1`. For REMAKE choose an effect type such as `source_grounded_diagnosis`, `corrective_operation` or `department_dependency`, provide the exact observed scene/shot locator and explain how the original source affected the diagnosis. Preserve all original LOCK/reference roles and verify the counterexample. A receipt is **not** a generated shot, independent film playback, studio endorsement or owner approval.

Cinematic Atlas's S10 index includes 46 proposed problem-to-KN routes, and `downstream_research_options` can suggest additional source-qualified light/sound/edit checks. Those are *unselected* checks, not an automatic instruction to apply, and cannot be entered in `actually_used_in_authored_decision_ids` without explicit new selection. Do not reveal private client material or any of the source records through the public MCP; the only new publicly available part of `remake_get_audit_method` is the present method contract.


**Production verification boundary:** A caller-provided Craft Context packet or a claimed SHA256 is not sufficient provenance. The verified OPS wrapper must reload the authorized local `atlasDir` and regenerate source candidate membership, source URLs, LOCKs, family routes and corpus digest before it can issue a source-use receipt. A public plugin has no such local private checkout and therefore must not claim verified Atlas usage.


## Optional frame-accurate and optical checks

An authorized private/local host can run the proposed OPS tools/craft_sequence_qa.mjs with an explicitly authored frame-based shot/multiscreen timeline, and tools/craft_optical_preflight.mjs with user-specified optical geometry, focal length, distances, camera height, format, aperture, CoC, FPS and shutter. The checks maintain source/canon LOCKs, distinguish author-approved in-shot and between-cut changes, and flag physically inconsistent draft instructions. Optical math uses only pinhole and thin-lens approximations, not a real calibrated lens, measured light, genuine source film or AI video playback. Neither test automatically rewrites a scene or proves artistic quality. Both are source code candidates on private OPS PR #168, not included in this public plugin or deployed to a host. Do not send private client media or Atlas records to a public MCP to perform these tests.

The authorized private OPS Workbench now also proposes `action:"feedback"`
(and `objekts_craft_feedback` on its stdio adapter). Supply the original local
`record` request, retained source/project digests and reviewer observations tied
to actual local result files configured at host startup with `--review-manifest`.

criteria actually reviewed; missing or inconclusive evidence remains explicit.
These are caller-reported observations, not independent media inspection,
provider execution or artistic acceptance. Proposed experiments grant no change
authority: preserve approved LOCKs/reference roles and use the normal revision
guard for authorized changes. No automatic adoption or retrieval reweighting.
This public product document neither installs that private host nor accepts
private result files, prompts, source records or review evidence through its MCP.
