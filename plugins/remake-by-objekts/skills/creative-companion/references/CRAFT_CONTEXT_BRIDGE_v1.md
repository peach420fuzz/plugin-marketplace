# REMAKE — source-qualified cinematic craft context v1

**Draft, not released.** The private role100 Cinematic Craft Atlas is not included in this public plugin. The public REMAKE MCP currently has no authenticated read access to private GitHub. `remake_get_audit_method({"section":"craft"})` returns the public method only, not the private corpus and not a creative verdict.

When a host has separately obtained an authorized local `objekts.craft-context/1` packet, inspect its `source_digest_sha256`, task/LOCK/asset authorities, candidate KN-IDs, provenance, source scope, counterexamples and proposed tests. Select only scene-relevant mechanisms. Connect authorial purpose, actor blocking, camera position, perspective/focus, motivated light/material, acoustic POV, edit and VFX finishing where causal. The actual scene, script, supplied image/video and latest user approvals remain authoritative. Do not mark an extracted interview as a watched film or a tested shot.

**Use log:** maintain private `considered_ids`, `used_ids`, `rejected_ids`, affected scene locator, original source, LOCK check, untested risk and real output QA. Retrieval does not prove artistic application; a source-inspired decision does not prove successful rendering. Never demand use of all relevant mechanisms as aesthetic decoration.

**Privacy:** do not send the private Atlas, confidential client assets or source snippets to the unauthenticated REMAKE MCP just to get instructions. This is an OPTIONAL host-side method. No automatic retrieval, project storage, model generation, outbound transfer or production validation is performed by this file. Source status remains research proposal until approved by owner.

## Integrated source decision receipts (draft)

With a private packet *actually supplied by an authorized host*, the host may record its final diagnosis using the local OPS module `tools/craft_consumer_receipt.mjs`. Schema: `objekts.craft-consumer-receipt/1`. For REMAKE choose an effect type such as `source_grounded_diagnosis`, `corrective_operation` or `department_dependency`, provide the exact observed scene/shot locator and explain how the original source affected the diagnosis. Preserve all original LOCK/reference roles and verify the counterexample. A receipt is **not** a generated shot, independent film playback, studio endorsement or owner approval.

Cinematic Atlas's S10 index includes 46 proposed problem-to-KN routes, and `downstream_research_options` can suggest additional source-qualified light/sound/edit checks. Those are *unselected* checks, not an automatic instruction to apply, and cannot be entered in `actually_used_in_authored_decision_ids` without explicit new selection. Do not reveal private client material or any of the source records through the public MCP; the only new publicly available part of `remake_get_audit_method` is the present method contract.
