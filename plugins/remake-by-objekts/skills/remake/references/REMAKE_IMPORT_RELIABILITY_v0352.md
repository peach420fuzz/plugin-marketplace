# REMAKE 0.35.2 — imported decision references

Malformed imported decision `source_ids` must be a JSON array. Null, numbers, booleans, strings and objects are refused with INVALID_SOURCE_IDS instead of crashing or treating characters/object keys as references. An invalid canonical packet is rejected before a delta changes it.

This release includes the existing 0.35.1 review contract for explicit keyed camera/sound locks and duplicate shot IDs on the stateless public MCP. Source helpers are optional and require an authorized local executor; no import hook, inference service or storage is added.

The 100-test Python regression suite exercises synthetic structural and media fixtures. It does not establish intended-host perception, independent directing quality, actual author approval or G1–G10 acceptance. Existing illustrative dialogues are examples, not real completed client projects.

Public submission still needs an actual intended-host demo and portal review; saving this private release is not official catalog publication.
