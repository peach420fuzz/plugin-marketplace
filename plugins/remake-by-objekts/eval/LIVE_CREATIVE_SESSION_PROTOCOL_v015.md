# Live creative session protocol v0.15 — the result is still unknown

This is a **ready-to-run evaluation**, not a completed independent study. Written eight-turn examples included with v0.15 are authored calibration artefacts; scoring them as actual customer consultations is disallowed.

## Experimental comparison

At least six creators supply permissioned original briefs/material, across: 2 ads (one product claim and one camera/product master lock), 2 narrative (one intentional ambiguity), 1 abstract no-fix loop, 1 multi-shot AI edit needing repair. No need to finish all lessons. Pre-declare the same materials, eight scripted *choices/corrections* wherever practical, and the creative objective before running each condition.

Each creator independently uses:
- A: ordinary selected base GPT with identical materials and no skill.
- B: private ChatGPT + installed Creative Companion.
- Optionally C: Claude without the Companion instructions, clearly separate baseline.

Do not tell the author an intervention is 'objectively better'. Have 2 qualified directors/editors blind-rate matched, source-redacted transcripts and final **paper edits**; record rater disagreement, not only a mean. Do not reuse an assistant-authored calibration case as a blind unknown evaluation case.

## Eight-turn execution evidence (each person)

1. Store a source revision digest (SHA-256 if file bytes accessible; else a stable user-provided ID and explicitly unknown hash).
2. Record exact user turn, assistant response, any observed files and accessible frames. No invented screenshots or timecodes.
3. Capture the state after each turn: approved, proposed, rejected, lock, unknown, revalidation.
4. On turns 4/6/8 inspect whether earlier constraints survived unchanged.
5. Save the full exported playable shot map and count one meaningful approved directing decision as completion — not the mere length of an answer.
6. Record source/scope permission and reviewer acknowledgement without publishing material or contacting outside parties.

## Expert rubric (0, 1 or 2; do not fake scores)

- Source truth: separates author text, visual observation and speculation.
- Directorial insight: the pivotal action/cut has consequences for viewer understanding.
- Teachability: beginner learns why rather than receiving stylistic adjectives.
- Production: specific, filmable blocking, timed structure, technical master/format constraints.
- Agency/continuity: later changes and rejections never silently override approved canon.
- Art/genre fit: not forcing a marketing hook into narrative or plot into abstraction.

Fatal: fabricated footage/timecodes, false brand performance guarantees, unconsented media transfer, overwriting LOCK, an imagined viewer test presented as real. Count N and denominators; if one fatal occurs do not declare the test passed. Do not convert score to 'virality probability'.
