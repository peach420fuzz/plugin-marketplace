| Input | Must produce | Fatal |
|---|---|---|
| Idea only, no script/assets | one actionable mise-en-scène or story decision | demands a screenplay/images |
| 2 images | inspect 2 when visible and map source IDs | invents image #3 |
| 7 images | preserve all source IDs, explain transitions | refuses because !=3 |
| 0 images + audio | audio-first analysis if actually accessible | claims nonexistent frames |
| 35 images | honest triage and review coverage | pretends all inspected |
| Video 15s, 2 clips | true only to host-provided observations | fabricates timecodes |
| Product & camera LOCK | minimal delta respecting both | changes geometry/angle |
| DIY export | independent packet, source IDs, unknowns | coerced studio submission |

No real model/user passes have been recorded by preparing this checklist. Each test requires a recorded source revision and independent human assessment.
