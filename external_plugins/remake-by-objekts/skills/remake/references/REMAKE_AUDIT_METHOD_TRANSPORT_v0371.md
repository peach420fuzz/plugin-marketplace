# Actual method delivery — 0.37.1 / public runtime 0.7.3-beta

An MCP connection alone previously exposed source/LOCK/draft helpers without the detailed production-audit curriculum. The new read-only `remake_get_audit_method` tool delivers the same allowlisted authored source used by the plugin. No user project, confidential media, external book text, private evaluation or credential is compiled into this method snapshot.

## Requests

- `{"section":"core"}`: current core, audit engine and full 22-function index. Read before substantial REMAKE work when no matching local method is loaded.
- `{"section":"departments"}`: all 22 detailed contracts. For smaller staged reads, `{"section":"departments","department_ids":["04","05","17"]}` returns those stable functions and lists omitted IDs. This transport selection is not a cap on audit scope.
- `{"section":"handoffs"}`: cross-department interfaces, production audit playbook and grounded studio bridge.

Arguments are strict. Unknown sections, extra fields, invalid/duplicate IDs, empty selections and IDs attached to a non-department section are rejected. There is no URL/path argument, arbitrary source fetch, account lookup or state mutation.

## What the response establishes

`method_version` and `method_sha256` identify one compiled snapshot. `source_files` lists SHA256 for the six public authored input files. The generator compiles only those explicit sources and reproducibly hashes their canonical data. Compare versions/hashes if switching between local and remote instructions; do not quietly combine different revisions as one authority.

`METHOD_TEXT_ONLY_NOT_AN_AUDIT_RESULT` means exactly that. The server returns instructions and contracts; the host model must read them, inspect authorized source material, apply judgment and preserve limitations. A correct transport result does not prove the model read it, followed it, inspected images, understood performance or produced professional criticism. Actual intended-host execution and independent quality evaluation remain open until performed.

The ten public tools remain stateless. Existing draft/LOCK guards, file integrity limits, media evidence boundaries, privacy and consent rules remain in force. Retrieving a method never authorizes media transfer to the studio, produces a quote or creates a human approval. The author retains their sources and choices.
